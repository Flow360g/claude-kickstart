# Summit Half Dome

A browser platformer that replaces the slides for the 45-minute Claude kickstart with Client Solutions. Everyone plays the Half Dome hike on their own laptop while Harry talks over it and runs live examples in Claude as people reach each trail marker.

## Run it

Open `index.html` in Chrome or Safari. No build step, no backend.

Deploy: `vercel deploy` from this folder, or drag the folder into Vercel.

## What's in it

| World | Stage | Topic |
|---|---|---|
| 1 | Happy Isles | Set Claude up once |
| 2 | Mist Trail and Vernal Fall | Pick the model for the job |
| 3 | Nevada Fall and Little Yosemite Valley | Connectors (touch the trail posts to connect them to the Claude beacon) |
| 4 | Sub Dome stairs | The four building blocks |
| 5 | The Cables | Client Solutions workflows: the TMC project, `/mi-to-monday`, `/wip-wrapup` |
| 6 | The Summit and the Visor | Claude in Chrome, Excel and Word, then the summit card |

- **Trail markers** (gold blocks with the dome): hit from below or press E to open a card with an animation.
- **Backpack items**: prompts to copy, plus downloads: both Half Dome skills as `.zip` files ready to upload, a SKILL.md starter, the project instructions template and the client context doc template. The summit card and the Backpack also download everything as one `.md` kit.
- **Ranger stations**: one question per world. Wrong answers explain why. Esc skips.
- **Campfire checklists**: what to do now, with Copy and Download buttons on each line. Ticks save on that laptop.
- **List view** (L): every card, prompt, checklist and question as a plain page, with the same buttons.

## Edit the words

All text lives in the `CONTENT` object at the top of the first `<script>` in `index.html`: cards, backpack prompts, checklists, quizzes, talk tracks and the ASCII level maps. The legend is in the comment above it.

The two skill files live in `ASSETS` (second `<script>`). Replace the text there when a skill changes.

Levels 2 to 6 are generated by `tools/levels.py`; edit the map in `CONTENT` directly, or change the script and paste its output back in.

## Controls

| Key | Action |
|---|---|
| Arrows or A / D | Move |
| Space, Up or W | Jump |
| E or Enter | Read a trail marker |
| Esc | Close |
| M | World map (jump to any world) |
| B | Backpack |
| L | List view |
| P | Presenter mode: talk tracks from the deck's speaker notes show on cards |

Links: `#world-1` to `#world-6` jump straight to a world. `#presenter` turns presenter mode on.

## Publishing as a Claude artifact

`python3 tools/artifact.py out.html` writes a copy without the `<html>`/`<head>`/`<body>` wrapper for publishing as a claude.ai artifact. Downloads use the artifact's download capability there, and a normal browser download everywhere else.
