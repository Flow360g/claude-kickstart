# Summit Half Dome: fact-check report (checked 6 October 2026)

Scope: every claim in claims.md, checked against live official sources (support.claude.com, anthropic.com, claude.com docs and directory) for a Claude Team plan on claude.ai web and the desktop app.

Two things to know before reading the tables:

1. **Team is still on the "Chat / Cowork" split.** On 16 September 2026 Anthropic began merging Cowork into every conversation (the "new Claude experience"). It is rolling out to Pro and Max first; Team is "to follow". Until it arrives, Team users still see "Chat" and "Cowork" options in the message box. Some settings names differ between the two experiences, and both are given below. Source: https://support.claude.com/en/articles/16761823
2. **"Settings" has been split in two.** Connectors and Skills now live under **Customize** (Customize > Connectors, Customize > Skills), not Settings. Personal, memory, usage and Cowork options are still under Settings. Admin controls are under **Organization settings**.

Most claims hold up. The main fixes are: Sonnet 5.5 has replaced Sonnet 5, connectors and skills moved to Customize, the Docs/Slides/Design plan claim is wrong, the projects redesign is Claude Code first, record-a-skill is Mac-only, and Granola's free plan limits what the connector can reach.

## Section B: Current how-to facts for the 11 topics

### 1. Instructions for Claude (personal preferences) and profile
- **Path:** Click your initials (lower left) > **Settings** > under **Instructions for Claude**, type your standing instructions. "Any instructions you add here will be applied to all of your conversations." Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features. Confidence: high.
- In the new Claude experience (Pro/Max now, Team later), it is **Settings > General > Instructions for Claude**, and the old Cowork **Global instructions** (Settings > Cowork > Global instructions > Edit) merge into it. Until Team moves over, Cowork tasks may also read Settings > Cowork > Global instructions. Source: https://support.claude.com/en/articles/16761823 ; https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork. Confidence: high.
- **Profile fields** (name, work function dropdown) are on the same Settings page (General/Profile). I could not confirm the current exact labels from an official page. Third-party guides cite "Select your work function" and "What preferences should Claude consider in responses?". Check them live before scripting them. Confidence: low.
- Project instructions apply only to chats in that project; Instructions for Claude apply everywhere. Source: as above. Confidence: high.

### 2. Memory
- **Admin first (Team):** "Owners control whether memory is available, and it's off for each member until they turn it on." An Owner or Primary Owner turns it on in **Organization settings > Capabilities**. Turning org memory off later **permanently deletes everyone's memory**. Owners can't view or edit members' memories. Source: https://support.claude.com/en/articles/11817273. Confidence: high.
- **Member:** **Settings > Memory** > turn on **Generate memory from chats**. In the same place, **Search and reference chats** is a separate toggle (on by default once rolled out). **Include sensitive topics in memory** is off by default. Confidence: high.
- **View and edit:** Settings > Memory > **Topics**. "Select any topic to read it, then use the edit icon to change it or select 'Delete' to remove it." You can also tell Claude "remember this" or ask it to forget something in chat. Confidence: high.
- **Per project:** "Each project has its own separate memory space and dedicated project summary." Moving a chat out of a project (Remove from project) moves it out of that project's memory. Confidence: high.
- **One-off opt-out:** New chat > "+" > turn off **Memory** before the first message, or use an incognito chat (ghost icon, top right). Memory is shared between chat and Cowork in the cloud, but not with local Cowork sessions. Confidence: high.
- Legacy accounts may still see memory under Settings > Capabilities ("View and edit memory"); a few Team orgs remain on the legacy experience. Confidence: medium.

### 3. Importing memory from ChatGPT or other assistants
- It exists: "Memory imports are available for Free, Pro, Max, and Team plans on the web and Claude Desktop." Memory must be on. Source: https://support.claude.com/en/articles/12123587-importing-and-exporting-your-memory. Confidence: high.
- **Steps:** (1) Go to **Settings > Memory > "Start import"**. This shows a ready-made export prompt. (2) Paste that prompt into ChatGPT (or another assistant) and copy its output. (3) Paste the output into the box and click **"Add to memory"**. (4) Optionally click **"See what Claude learned about you"**. Confidence: high.
- It is "experimental and still in active development". Claude keeps mainly work-related details, so imported personal details may be dropped. Review the results under Topics. Confidence: high.
- Legacy path: Settings > Capabilities > Memory > "Start import". Confidence: medium.

### 4. Local file and folder access in the desktop app (the trusted folders question)
- **The setting exists.** In the current Team (Cowork) experience: **Settings > Cowork > "Trusted Cowork folders" > Manage**, where you can review and remove folders (PCWorld; the official page could not be fetched). In the new Claude experience, Anthropic says: "Folders you gave Cowork access to are listed under **Trusted folders**" in Settings, and the Cowork output folder is under **Storage folder**. So the card's concept is right; the label varies by experience. Source: https://support.claude.com/en/articles/16761823 ; https://www.pcworld.com/article/3224710/5-claude-privacy-settings-you-should-check-right-now.html. Confidence: high that it exists; medium on the exact label for Team today.
- **How folders get added:** You don't pre-build a list. When starting a Cowork task in the desktop app, choose a folder from the message box (third-party guides call the control "Work in a folder" or "Work in a project or folder"). A permission prompt then offers one-time access or **Always allow**. Folders you always allow become trusted. You can also attach a local folder as a Cowork project's Context. Confidence: medium on button labels.
- **What Claude can reach:** "Claude can only read and write files in folders you've connected." Cloud sessions reach those folders "only while the desktop app is open". Claude asks before permanently deleting files. Admins on managed devices can restrict folders with `allowedWorkspaceFolders`. Source: https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork ; https://claude.com/docs/third-party/claude-desktop/local-access. Confidence: high.
- **Best practice from Anthropic:** "Consider creating a dedicated working folder for Claude rather than granting broad access." Never trust your whole home folder. Source: https://support.claude.com/en/articles/13364135-use-claude-cowork-safely. Confidence: high.
- Computer use is not available on Team. Source: https://support.claude.com/en/articles/14128542. Confidence: high.

### 5. Models in claude.ai now
- **Opus 5.5** (22 Sept 2026): "performs at the level of Claude Fable 5.1 on most work and costs 40% less to run than Opus 5"; output 30%+ faster; five-hour limits raised on Pro, Max, Team and seat-based Enterprise; a one-off saved rate-limit reset. Reported (ClaudeDevs) as the default on paid plans. Thinking is always on. Source: https://www.anthropic.com/claude-opus-5-5. Confidence: high (default: medium).
- **Sonnet 5.5** (28 Sept 2026) replaces Sonnet 5 as the everyday fast model: 30%+ faster, up to 30% cheaper, and "strongest at well-scoped everyday tasks ... polished documents, slides, and spreadsheets." Source: https://www.anthropic.com/claude-sonnet-5-5. Confidence: high.
- **Haiku 5.5** is announced "in the coming weeks", with no date. Haiku 4.5 is not confirmed in the current claude.ai picker. Confidence: medium.
- **Fable 5.1** (1 Sept 2026) is in the picker on all paid plans. On Team **standard** seats it is billed via **usage credits**; **premium** seats include it, up to 50% of weekly limits. Requests in some sensitive areas fall back to Opus. Source: https://support.claude.com/en/articles/15424964. Confidence: high.
- **How to switch:** click the model name next to the send button > choose a model (or **More models**). The same menu has **Effort** (Low, Medium, High, Extra high, Max; the apps default to Medium for Sonnet 5.5). Check usage in **Settings > Usage**. Source: https://support.claude.com/en/articles/8664678. Confidence: high.

### 6. Connectors
- **Admin (Team):** An Owner or Primary Owner goes to **Organization settings > Connectors** > **Browse connectors** > choose one > **Add to your team**. "Enabling a connector makes it available to your team, but it doesn't automatically grant anyone access. Each person still needs to authenticate individually." Source: https://support.claude.com/en/articles/11176164. Confidence: high.
- **Member:** **Customize > Connectors** > "+" > find the connector > **Connect** > sign in. Per chat: "+" (or type "/") > **Connectors** > toggle on. Confidence: high.
- **Read vs write and approvals:** Owners can restrict actions org-wide (for example read but not write). Under **Customize > Connectors > [connector] > Tool permissions**, each tool or category can be set to **Always allow / Needs approval / Blocked**. In Cowork, the permission mode is **Manual** (formerly "Ask before acting", the default in the new experience), **Auto**, or **Skip**. The Team org setting **Allow "Always allow" for connector tools** is **off by default**, so write tools ask per task. Source: https://support.claude.com/en/articles/11176164 ; https://support.claude.com/en/articles/13345190 ; https://support.claude.com/en/articles/13455879. Confidence: high.
- **The four you care about all exist in the directory:** Microsoft 365 (SharePoint, OneDrive, Outlook, Teams; write tools need admin plus Entra consent), monday.com (read and write: create and update items, post updates), Slack (Team/Enterprise only; install the Claude in Slack app first; can search and post), and Granola (read-only; see the free-plan limits in A-8). Source: https://claude.com/connectors/monday ; https://claude.com/connectors/granola ; https://claude.com/docs/connectors/slack.md ; https://support.claude.com/en/articles/15183774. Confidence: high.

### 7. Design systems, Docs, Slides and Design
- Since 16 Sept 2026 you can ask for a design, deck or doc "in any conversation", or start from a template in the **Artifacts** tab, or pick **"Output"** in the message box. Docs can also start with **/docs**. Source: https://support.claude.com/en/articles/17153992 ; https://support.claude.com/en/articles/16923645. Confidence: high.
- **Plan availability:** Templates (Design, Slides, Docs) and design systems are "in beta on paid plans ... **on by default on Pro, Max, and Team plans**", and off by default on Enterprise. Artifacts require **Cloud code execution and file creation** on (Team: Organization settings > Capabilities). Confidence: high.
- **Design system:** "On Team and Enterprise plans, you only need to do this once, and everyone's work picks it up after that." Build it from a chat ("Ask Claude to build a design system from your connected apps, uploaded files, Figma files, decks, logos, and fonts"). Manage it in **Settings > Design systems**. It applies to designs and decks. Source: https://support.claude.com/en/articles/14604397. Confidence: high.
- **Exports:** Docs export to Word, PDF, Markdown and Google Docs. Decks export to PowerPoint and PDF. Designs export to .zip, PDF, PowerPoint or HTML. Confidence: high.

### 8. Artifacts and projects
- Artifacts open beside the chat, are saved to the **Artifacts** tab in the sidebar, start private, and can be shared. On Team, each viewer connects their own apps. Source: https://support.claude.com/en/articles/17153992. Confidence: high.
- **Chat projects:** Projects > **+ New Project** > choose visibility (private, or share with org). Add files via "+" in **project knowledge**, and use **Set project instructions**. "Context is not shared across chats within a project unless the information is added into the project knowledge base." Source: https://support.claude.com/en/articles/9519177. Confidence: high.
- **Cowork projects:** Projects > "+" > Start from scratch / Import from a Claude project / Use an existing folder. Each has **Instructions, Scheduled tasks, Context, Memory**. Source: https://support.claude.com/en/articles/14116274. Confidence: high.
- **Sharing on Team:** **Share project** > add people > **Can view** ("see project contents, knowledge, and instructions, and chat within the project") or **Can edit** (change instructions and knowledge). Each person's own chats in a shared project stay private to them, and memory is per user ("Owners can't view or edit a user's individual memories"). Confidence: high (chat privacy: medium).
- **Redesign (17 Sept 2026):** a project becomes one conversation with parallel threads, a coordinator, shared memory and a Library. It is in beta in **Claude Code** for select Pro/Max users first; "chat, Cowork, Team, and Enterprise will follow." Source: https://support.claude.com/en/articles/9517075-what-are-projects. Confidence: high.

### 9. Skills
- **Where:** **Customize > Skills**. On Team, skills are enabled at org level by default (Owner: **Organization settings > Plugins & skills > Policy** tab: *Cloud code execution and file creation* and *Skills*). Source: https://support.claude.com/en/articles/12512180. Confidence: high.
- **Upload a .zip:** Customize > Skills > **"+"** > **"+ Create skill"** > **"Upload a skill"** > choose the zip (skill folder at the zip root, folder name matches skill name, contains skill.md). Confidence: high.
- **Make one with Claude:** Ask "turn this conversation into a skill", or use the built-in **skill-creator** skill (switch it on under Customize > Skills if needed). Claude drafts the files beside the chat, and you save them to your skills. "/" opens the slash menu in claude.ai (used for /docs, /schedule, /deep-research), and skills can be invoked by name. Source: https://support.claude.com/en/articles/12512198 plus third-party guides. Confidence: medium (exact save-button label not confirmed).
- **Record a skill:** Mac desktop app, in Cowork only: "+" > **Record a skill**, or Customize > Skills > **Add** > **Record your screen**. Pro, Max and Team only; about 10 minutes max; not on Windows. Confidence: high.
- **Sharing on Team:** Customize > Skills > "..." > **Share** (specific people; recipients get a view-only copy). Use **Publish to org** to add it to the org library. The "Skill sharing" toggle is on by default for Team, but **Share with organization** is off until an Owner enables it in Organization settings > Plugins & skills > Policy. An Owner can also provision skills for everyone. Confidence: high.

### 10. Scheduled tasks and manual tasks
- Available on all paid plans, in Cowork (Team) and in the new experience. Source: https://support.claude.com/en/articles/13854387. Confidence: high.
- **Create (Team, Cowork):** click **Scheduled** in the left sidebar > **New task** (top right) > **Create with Claude** or **Set up manually**. Set up manually means task name, prompt, approval mode, frequency (**hourly, daily, weekly, on weekdays, or manually**), and optionally a model and folder > **Save**. You can also type **/schedule** in a Cowork task. Cowork projects have their own Scheduled tasks section. Confidence: high.
- **Manage:** Scheduled page > edit, pause, resume, delete, or **run a task on demand** (this is the "manual task with a run button"). Confidence: high.
- **Cloud:** "Scheduled tasks run in the cloud, so they don't need your computer to be awake or the desktop app open." They need the Team org's **Run Cowork in the cloud** setting on (the default for Team). A task that needs local files only runs while the desktop app is open. They use the creator's connectors and plugins. Confidence: high.
